# CoreLedger

CoreLedger is a modern web-based budgeting and financial management application built with Next.js and React. It provides a structured interface for managing budgets and financial data with a serverless PostgreSQL backend.

## Features

* Budget management
* Financial data management
* Responsive web interface
* Server-side functionality with Next.js
* Serverless PostgreSQL database integration
* Middleware-based request handling

## Tech Stack

* **Next.js 14**
* **React 18**
* **Neon Serverless PostgreSQL**
* **JavaScript**
* **CSS**

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/00AbdullahZahid/CoreLedger.git
cd CoreLedger
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file and add the required Neon database configuration.

```env
DATABASE_URL=your_database_url
```

### 4. Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Production

Build the application:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
